# 配色台 — UI Color Simulator

アプリやWebページのUI配色を、スマホ画面のモックアップ上でシミュレーションできるツールです。

## 使い方

1. `ui-theme-simulator.html` をブラウザで開くだけで動作します（インストール不要）
2. 左側の「カラー編集」で自由に色を作るか、「テーマプリセット」から選んで配色を試せます
3. 「配色の割り当て」で、ヘッダー・ボタン・アクセント・サブ背景にどの色を使うか指定できます
4. 右側に3種類のスマホ画面プレビューが表示され、配色が即座に反映されます

## できること

- パレットの色数を2〜5色で切り替え
- 各色をカラーピッカー or HEXコード入力で編集
- ミニマルで洗練された配色プリセットを6パターン収録
- 「ランダム」ボタンで調和のとれた配色を自動生成
- 気に入った配色を「マイパレット」に保存（名前付き）
- CSS変数・HEXコードをワンクリックでコピー
- スマホ表示に対応（画面幅980px以下でレイアウトが縦並びに切り替わり）

## 配色の保存について

保存機能は動作環境によって自動で切り替わります。

- **Claudeのアーティファクトとして開いている場合**: Claude専用の保存領域を使用
- **このファイルを直接ブラウザで開いている場合（GitHub Pagesなど）**: ブラウザの`localStorage`を使用

どちらの環境で保存したパレットも、同じ環境内でのみ引き継がれます（Claude側とブラウザ側でデータが共有されるわけではありません）。

## 利用について

このツールは自由に使っていただいて構いませんが、コードの改変・再配布はご遠慮ください。

## 公開URL

GitHub Pagesを有効化すると、以下のような形式でアクセスできます。

```
https://<ユーザー名>.github.io/<リポジトリ名>/ui-theme-simulator.html
```

有効化手順: リポジトリの `Settings` → `Pages` → Branch を `main` / フォルダを `/(root)` にして保存。数分でURLが発行されます。
